# My Social network 
простая соц-сеть на Fastapi

## Функции
- Авторизация пользователей
- Чаты в реальном времени (WebSocket)
- Поиск пользователей
- Посты
- лайки
- подписки
- комменты

## Стек
- Python
- FastAPI
- WebSocket
- PostgreSQL
- Sqlalchemy
- html
- css
- js

## Запуск

```bash
git clone <repo>
cd my-project

python -m venv venv
venv\Scripts\activate  # Windows

pip install -r requirements.txt

uvicorn main:app --reload
```
